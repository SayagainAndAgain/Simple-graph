# 🚀 Epic Data Visualizer Pro

Сучасний, потужний інструмент для візуалізації даних, створений на основі вашого початкового проекту.

## ✨ Нові Можливості

### 📊 Типи Графіків
- **Лінійний** - класичний лінійний графік
- **Scatter** - точкова діаграма розсіювання
- **Стовпчики** - вертикальні стовпчикові діаграми
- **Площа** -(area chart) з градієнтним заповненням

### 🎨 Персоналізація
- Вибір кольору лінії
- Налаштування розміру точок
- Регулювання товщини лінії
- Показ/приховування сітки
- Анімація малювання ліній
- Темна/Світла тема

### 📈 Статистика в реальному часі
- Кількість точок
- Мін/Макс значення X та Y
- Середні значення X та Y

### 💾 Експорт даних
- PNG - експорт графіку як зображення
- CSV - експорт даних у таблицю

### ⌨️ Гарячі клавіші
- `Enter` - додати точку
- `Ctrl+Z` - скасувати дію
- `Ctrl+S` - експортувати PNG

### 🎯 Інтерактивність
- Список всіх точок з можливістю видалення
- Hover ефекти на елементах
- Toast сповіщення про дії
- Історія дій (до 50 кроків)

## 🛠 Технології

- HTML5 Canvas для рендерингу
- CSS3 змінні для тем
- Vanilla JavaScript (ES6+)
- LocalStorage для збереження налаштувань

## 🚀 Швидкий старт

Просто відкрийте `index.html` у будь-якому сучасному браузері!

```bash
# Або запустіть локальний сервер
python -m http.server 8000
# Відкрийте http://localhost:8000
```

## 📝 Використання

1. Введіть координати X та Y
2. Натисніть "Додати точку" або натисніть Enter
3. Оберіть тип графіка
4. Налаштуйте вигляд за бажанням
5. Експортуйте результат!
